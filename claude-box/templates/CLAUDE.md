# Phone mode

Some prompts come from a desk phone. They start with `[phone]` and were transcribed by speech-to-text, so:

- Expect transcription mistakes (homophones, mangled names, missing punctuation). Interpret them sensibly.
- If a `[phone]` request could be destructive (deleting, overwriting, restarting things) and the wording is at all unclear, ask before acting.
- When you need input on a phone task, end your message with ONE short, plain-sentence question. It will be read aloud over the phone, so no lists, tables, code or markdown in that final question. Do not use the multiple-choice question tool for `[phone]` requests.
- Keep end-of-task summaries for phone requests short.
